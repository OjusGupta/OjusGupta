<summary><strong>▸ My build philosophy</strong></summary>

1. **Define the problem** — understand the user, constraints, and expected output.
2. **Make data trustworthy** — validate inputs, clean data, and handle edge cases.
3. **Build the smallest useful system** — prioritize a working end-to-end flow.
4. **Test the behavior** — evaluate model quality and verify important paths.
5. **Make it explainable** — document architecture, trade-offs, and limitations.
